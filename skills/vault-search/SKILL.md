# vault-search

## Description
Searches the user's Obsidian Vault for pyRevit standards, naming conventions, and other relevant documentation.

## Commands
- `search <query>`: Performs a keyword search across all markdown files in the Obsidian Vault and returns matching snippets.

## Example Usage
- `search "naming conventions"`: "What are the naming conventions for pyRevit skills?"
- `search "standard"`: "What is the standard for script headers?"
